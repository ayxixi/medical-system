# ADR 目录说明

## 目的

本目录用于保存架构决策记录（Architecture Decision Record）。当项目做出需要长期保留的正式技术决策时，应在此记录背景、决策内容、原因与影响。

## 适合记录的事项

- 核心数据模型调整
- 认证与权限模型调整
- 存储与部署方案调整
- 跨模块的关键架构取舍

## 不适合记录的事项

- 日常实现步骤
- 临时排查过程
- 单次会话进展

这些内容更适合放在实施记录或计划文档中。

## 推荐模板

建议每份 ADR 至少包含以下章节：

1. 状态
2. 背景
3. 决策
4. 原因
5. 影响
6. 备选方案
7. 关联文档

## 命名建议

- `0001-主题.md`
- `0002-主题.md`

编号用于保持决策历史的可追溯性。
