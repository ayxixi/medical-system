# 测试运行手册

## 目的

本文档用于说明本项目当前的测试类型、常用命令、执行前提与排查重点。

## 测试范围

当前测试主要包括：

- 后端单元测试
- 后端账号隔离 e2e 测试
- 前端测试脚手架与基础测试能力

## 后端测试

### 常用命令

在 `apps/server/` 下执行：

```bash
npm test
```

如需串行执行，便于定位输出：

```bash
npm test -- --runInBand
```

### 关注点

- 认证与登录逻辑
- 账号隔离
- Service / Repository 的领域行为
- 成员删除边界与附件清理队列保护/重试
- Prisma 测试库初始化

### 常见问题

1. 环境变量缺失
   - 检查 `JWT_SECRET`、`DATABASE_URL`、`FILE_STORAGE` 等配置是否已注入。
2. 测试库初始化耗时较长
   - 账号隔离 e2e 测试会在独立临时目录应用 Prisma 迁移，验证实际迁移中的 SQLite 触发器。
3. 终端工作目录错误
   - 执行测试前需确认当前目录为 `apps/server/`。

## 前端测试

### 常用命令

在 `apps/web/` 下执行：

```bash
npm test
```

或：

```bash
npm run test:watch
```

### 当前状态

- 前端已接入 Vitest。
- 自动化测试仍有继续扩展空间，建议优先覆盖登录流程、受保护路由和关键业务页面。

## 建议的验证顺序

1. 先执行后端测试，确认账号隔离和基础业务逻辑稳定。
2. 再执行前端测试与手工联调。
3. 如涉及接口改动，补充文档与计划文件同步检查。
