# AI 问诊配置

在运行 Nest 后端的环境中启动兼容 OpenAI Chat Completions 的模型服务。模型应能以本机或局域网的 IPv4 地址从后端访问。

在 `apps/server/.env` 中加入模型清单，模型 ID 可在模型服务中查看。

```dotenv
AI_MODELS_JSON='[{"id":"ollama","name":"本地问诊模型","model":"qwen2.5:7b","baseUrl":"http://127.0.0.1:11434/v1"}]'
```

可在 JSON 数组中添加多个模型。若某个服务需要密钥，在对应条目中加上 `"apiKeyEnv":"AI_MODEL_KEY_OLLAMA"`，再在同一环境中设置 `AI_MODEL_KEY_OLLAMA`。启用或移除模型后重启后端。Docker 中的 127.0.0.1 指应用容器自身，请填应用容器实际能访问的私有 IPv4 地址。服务会在基础地址后追加 `/chat/completions`。

登录后打开「AI 问诊」，选择模型并测试连接。连接测试只发送固定测试文本。自定义端点导入使用 Polaris 的 `customendpoint` 数组格式，模型名和地址均匹配服务端清单时才会生成可选草稿。默认选择保存在同一浏览器的当前账号下。

问诊时可选择最多五条病程记录。点击「预览将发送的内容」，核对模型、地址和文字，再点击「确认发送」。回复用于整理病程与就诊问题。当前每次请求独立处理，页面不保存问诊历史。
