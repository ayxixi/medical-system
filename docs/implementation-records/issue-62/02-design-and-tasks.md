# 设计与拆分

状态：已记录

- 在 User 关系下新增独立 HealthLog 表，时间、记录类型、体温、药名/用量、症状和备注按需存储；外键级联删除成员记录。
- 增加受 JWT 保护的 HealthLog CRUD API。读写都通过成员关系约束 accountId，避免跨账号访问。
- Web 增加“西西记录”页面和路由，移动底栏适配四个入口。
- 页面顶部显示当前成员与体温概览/7 日趋势；体温、服药、症状/日常情况分别提供快捷入口。
- 录入面板默认当前时间；症状使用常见选项，药名可从近期记录快速选择；用户始终可修改成员和录入值。
- 时间线提供 7/30/90 天范围，按时间倒序，支持编辑和删除，空状态和错误反馈清楚。
- SQLite 仅新增数据表和索引，使用 additive migration 保留已有用户、就诊及附件数据。
