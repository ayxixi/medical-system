# 实施记录目录说明

## 目的

本目录用于保存按时间或主题组织的实施记录，记录某次任务推进过程中完成了什么、为什么这样做、验证结果如何，以及仍有哪些后续事项。

## 适用范围

适合记录以下内容：

- 一次较大的功能实现
- 一次阶段性重构
- 一次重要缺陷修复
- 一次跨前后端联动改造

## 与其他文档的区别

- 当前状态与优先级，请查看 [../PLAN.md](../PLAN.md)
- 工程全景，请查看 [../ARCHITECTURE.md](../ARCHITECTURE.md)
- 专题设计，请查看 [../design/](../design/)
- 会话续接说明，请查看 [../../PLAN_USAGE.md](../../PLAN_USAGE.md)

## 命名建议

建议采用以下命名方式：

- `YYYY-MM-DD-主题.md`
- `YYYY-MM-阶段总结.md`
