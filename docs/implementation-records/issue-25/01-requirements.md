# 需求与验收

状态：已记录

关联 Issue #25。

面向自托管部署，加入应用主机本地 RapidOCR 中文图片识别与 faster-whisper 中文录音转写。前端支持拍照/选图、录音/停止；识别结果只回填到可编辑的诊断内容或就诊备注，必须由用户执行原有保存操作才写入数据库。

媒体只能临时处理，必须限制 MIME/大小/时长/请求耗时，调用完成或失败均清理临时文件；敏感媒体和识别内容不写日志/审计，不调用第三方识别 API。Python worker 默认可选、不启动、不影响现有手动功能，且只能处于自托管内网。

验收：Nest/前端/Python静态构建或语法检查通过；缺 worker 时现有服务照常运行，调用识别有可理解提示；README/Compose 文档记录可选依赖、模型预热和启用方法。
