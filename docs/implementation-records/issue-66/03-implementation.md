# 实现记录

状态：已记录

新增 `HealthReminder` 数据表、只增 SQLite migration 和按账号隔离的 CRUD/action API。每日提醒由服务端使用用户提供的 IANA 时区及本地时间计算下一次日历日提醒，跳过已完成的本次计划；稍后操作只设置独立的十分钟 snooze 时间，不改变每日计划。

“西西记录”页新增提醒管理卡片，支持创建/编辑/暂停/恢复/删除、单次/每日重复、到期提示、稍后十分钟和完成操作。体温/服药提醒可直接打开相应录入面板；记录保存成功后自动完成该提醒。提醒页每分钟轮询，页面说明明确指出关闭网页时没有系统通知。账号 JSON 导出包含提醒。
