# 设计与拆分

状态：已记录

- 新增独立 HealthReminder 模型，通过家庭成员关联账号；保存提醒种类、标题、备注、下次时间、时区、每日重复、本次稍后时间和启用/完成状态。
- 新增受认证保护的提醒 CRUD 与提醒动作 API；仓储层使用成员关系 accountId 条件。
- 西西记录页面增加提醒列表和编辑面板、到期提示和快速跳转病程记录入口。
- 每日提醒在到期后完成时按记录时区的本地时间推进到下一个日期；稍后提醒只暂缓本次，不改变每日计划时间。
- 前端在西西记录页保持打开时每分钟轮询提醒；不请求浏览器推送权限、不承诺后台闹钟。
- 新增 SQLite additive migration；同步接口、架构和计划文档。
