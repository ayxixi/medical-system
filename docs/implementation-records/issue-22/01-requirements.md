# 需求与验收

状态：已记录

关联：Issue #22（业务操作审计与账号 JSON 导出）。

## 目标

1. 为已认证业务写请求记录操作审计元数据，以便后续定位变更来源。
2. 提供当前账号的 JSON 数据导出，支持用户备份自己的业务数据。
3. 保留本地 SQLite、现有数据库数据和本地附件，不在此任务中迁移或清理旧数据。

## 范围与隐私约束

审计只保存账号 ID、控制器/操作名、资源类型和 ID、HTTP 方法、状态码、成功标记及时间。不得保存请求正文、查询字符串、诊断/用药文本、密码、令牌、附件内容或文件内部路径。仅记录通过 JWT 认证的写请求；认证和注册请求不纳入本审计表。

`GET /export` 返回版本化 JSON，包含账号基本信息、家庭成员、就诊、诊断、用药及附件元数据。不得包含密码哈希、令牌版本、附件内部路径、存储文件名或附件内容。数据查询必须限制在当前认证账号。

## 验收标准

- 审计记录与账号关联，并按账号、时间建立查询索引。
- 每个已认证 POST/PATCH/PUT/DELETE 请求在成功或失败后留下审计元数据，审计写入故障不改变原请求结果。
- 跨账号无法通过导出读取其他账号数据。
- 导出包含 `schemaVersion` 和 `exportedAt`，仅包含约定业务数据和附件公开元数据。
- 新迁移可部署到已有 SQLite 数据库，不删除或重建现有数据/附件。
- README、实施计划及六阶段产物保持同步。
