# 设计与任务拆分

状态：已记录

## 设计

- Prisma 新增 `AuditLog`，通过 `accountId` 外键关联账号；账号删除时随账号级联清除审计行。
- 使用全局 `APP_INTERCEPTOR` 捕获已认证 HTTP 写操作的成功/异常结果。审计服务只接受白名单元数据，不传递 request body、query 或原始 URL；审计写入异常仅记录服务端警告。
- 新增受全局 JWT 守卫保护的 `GET /export`。服务端按 `accountId` 查账号及用户关联数据，并显式选择附件公开元数据字段。
- 使用前向迁移创建新表和索引，不重建现有表。
